# Generated artifacts

This directory contains small, reviewable reports and the MiniCity screenshot.

The full 365-day SQLite database, release archive, and frozen binaries are
kept in the downloadable release package because GitHub web upload has a
single-file size limit. The source repository remains fully runnable and can
regenerate those outputs with the scripts in `scripts/`.

All outputs are simulation results only; they are not real-world policy
predictions.
