# Changelog

## 0.1.0 — 2026-10-04

- Added deterministic MiniCity Agent-Based Simulation core.
- Added citizens, households, businesses, goods, money, housing, labour,
  education, information diffusion and multi-dimensional social relations.
- Added transaction ledger, policy comparison, snapshots, SQLite persistence,
  health monitor and annual reports.
- Added Tkinter map/dashboard and scenario editor.
- Added 365-day and 100-seed validation scripts.
- No paid model API is used by the project.
